AR DIGITAL CREATES — IMAGE UPDATED WEBSITE

This package contains the AR Digital Creates website with the supplied:
- Hero image
- Client logos/images
- Founder photo
- Four team photos

Open index.html to preview it locally.

For Vercel:
1. Upload the contents of this folder to your GitHub repository.
2. Import that repository into Vercel.
3. Deploy with the default settings for a static site.

The visual direction follows the existing AR Digital Creates dark/gold design and keeps the supplied images unchanged.
